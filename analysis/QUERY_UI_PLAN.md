# 查询目录与详情联动最小修复计划

日期：2026-10-10。模型沿用 Astra low。本轮仅规划 UI 修复，不改核心解析、匹配或知识契约。

## 结论与依据

已读取 `site/app.mjs`：目录始终过滤全局 index，片段提交仅更新解析行，启动时默认预览首条已核对知识；previewSequence 只保护部分详情请求，未覆盖输入变化和 querySingle 返回。因此输入与目录、详情缺少共同的当前查询状态。最小修复集中在页面状态联动及必要按钮，不调整孤立 server 的 context 推断。

## 实施范围与行为

1. 页面区分“当前查询候选”和“全部目录”两种模式。提交立即切到当前候选模式、清空旧目录与详情及选中态。成功解析后，目录仅显示本次各项 match.candidates 按 id 去重的并集，保留 registration_only 标签；旧搜索、模块、context、阶段和“仅已核对项”筛选不得隐藏本次候选。候选计数以此集合为准，初次提交完整展示。
2. 仅当本次恰有一条解析完整的指令，且匹配为 matched 或 context_required、候选恰一项时自动预览，并明示“本次输入的唯一候选知识预览”。context_required 状态必须保留，不宣称配置适用性已确认；registration_only 同样允许预览且保留未核实说明。错误状态下即使 candidates 仅一项也不自动预览。
3. 多条输入即使去重后仅一候选，也先显示“本次输入包含多条指令，请选择要查看的候选”；单条存在歧义时显示“本次输入存在多个候选，请选择模块/条目”。目录和解析行的候选点击均预览对应条目，不能保留默认 lua_load_resty_core 或上次详情。孤立 server 的未知 context 保持原结果，提示“请提供外层 http 或 stream 等所属块，以确定上下文”，不自行选定子系统。
4. 增加显式“浏览全部目录”入口；点击切到全局目录，恢复全局筛选能力，清空查询选中态及详情，显示“全部目录浏览，请选择条目”。不能把全局计数或所选知识表述为本次输入匹配结果。再次提交即回到当前候选模式。普通启动不默认加载首个条目；明确 URL id 的永久链接仍可预览，注明为链接指定条目。
5. 文本输入、输入模式、查询 context/module 变化以及示例填入，都立即撤销旧解析结果、候选、详情和选中态，提示“输入已变化，请重新查询”。空输入、解析错误、未知、索引/网络失败均不得遗留旧展示；解析错误时可显示本次错误及已解析项诊断，但不发布可选候选、不自动预览。未知显示本次未找到候选；详情请求失败清空其加载态和选中态，保留本次候选供重选，显示明确失败提示。
6. 使用页面级递增查询代次和详情请求序号：输入变化、提交、模式切换使旧请求失效；每次候选选择使旧详情请求失效。querySingle、详情读取、启动深链接等异步回调在写目录、状态、详情或按钮状态前都核对捕获的代次/序号。成功和失败分支均检查；旧请求不得恢复旧详情、覆盖错误或清空新结果。AbortController 可取消请求，但代次检查是正确性保障。不为此增加状态管理框架。

## 可验收检查

| 操作 | 通过条件 |
|---|---|
| 提交用户 server 片段 | 目录为本次候选去重集合，含 registration_only；未知 context 提示补充外层块；详情等待选择，无默认旧条目 |
| 单条 matched / 单条唯一候选 context_required | 自动预览当前条目，后者保留 context_required 与预览说明 |
| 多条输入 / 同名歧义 | 不自动选第一条，显示本次等待选择提示，点击后详情与候选 id 一致 |
| 预先设置全局筛选，再提交 | 当前候选不被旧筛选隐藏，计数等于候选集合数量 |
| 输入改动、切模式、改查询选项、点示例 | 旧详情/目录/解析结果立即撤销，未提交时不展示旧匹配 |
| 空白、解析错误、未知、索引失败、详情失败 | 显示相应本次状态，无旧详情；详情失败仍可从本次候选重新选择 |
| A 请求延迟，改输入提交 B；或先点 A 再点 B | A 后到的成功或失败均不能改写 B 的目录、详情、提示或加载状态；启动深链接迟到也遵守此规则 |
| 浏览全部目录，再提交查询 | 全局模式有明确标识；再次提交恢复仅当前候选且撤销全局详情 |

实施以 `site/app.mjs` 为主，按钮及提示所需的 `site/index.html`、样式按需最小修改；不改 `src/core/`、MCP、知识 JSON 或两份基线。验证重点为状态切换和受控延迟请求，补必要回归检查并实际操作浏览器；不以核心解析测试通过代替 UI 验收。审核逐项记录结果，失败返回实施修正。本规划任务仅写本文件。
