## 直接执行：最小改动

### R1：美元后开花括号不强制闭合

`src/core/parser.mjs:70–71` 删除寻找闭合 `}`、检查其间字符并报错的分支，改为保留 `$` 后连续 `{`。固定 nginx 的 `variable` 状态在遇 `{` 的提前继续分支没有清零，因此连续 `{` 同样不能被误认作开块。其他字符后的真实 `{`、引号与反斜杠路径不改。

人工输入 `pid /tmp/${demo;` 现在返回一个完整指令，参数和 `raw_args` 均为 `/tmp/${demo`。这仅是文本参数，不证明路径可创建或现场配置有效。带变量语义的指令即使词法通过，也不代表参数个数、表达式或指令回调接受它。

新增测试位于 `test/parser.test.mjs:103`、`:126`，覆盖闭合/未闭合形式、连续 `{`、分号、紧邻真实块、转义美元/花括号、引号、原始参数、结束位置、后续上下文、外部引用及结构错误。

### R2：Lua 短字符串的 z 转义

`src/core/parser.mjs:102–106` 在已有反斜杠分支中识别 `z`，跳过连续 ASCII 空白 `[ \t\v\f\r\n]`，再继续扫描当前字符串。未使用 JavaScript 的宽泛 `\s`。保留原反斜杠 CRLF 续行、普通转义、短引号、长括号、注释和块深度逻辑。

新增测试位于 `test/parser.test.mjs:316`、`:336`、`:348`：单/双引号，LF、CR、CRLF、LFCR、混合 ASCII 空白和零空白；字符串内花括号不产生伪配置指令；块后指令的 offset、行列和上下文准确。反例覆盖转义反斜杠后的普通 `z`、NBSP、非连续空白后的换行、普通未转义换行、未闭引号及未闭块。

### LuaJIT 与配置块词法器：必须分开的正例和反例

下文 `<LF>` 代表一个实际换行，不是六个字面字符。

正例块体：` local s = "a\z<LF>b"; ngx.say(s) }`。按固定源码，短字符串匹配遇 LF 后返回搜索态，但此前缀没有内部花括号等标记；搜索到真正末尾 `}` 时，读取函数保留整个前缀，块解析可将完整 Lua 文本交给 inline 处理器。该结论是源码路径判断，本轮未编译或运行 OpenResty。

必要反例块体：` local s = "a\z<LF>}"; ngx.say(s) }`。LuaJIT 的字符串词法允许 z 后换行，但固定 lua-nginx 块词法器返回搜索态后，会先把字符串内 `}` 当成右花括号，可能在层级从 1 到 0 时提前结束块。不能声称这一输入已通过原生配置加载。

`:336` 的字符串内花括号回归验证的是计划要求的网站 Lua 边界扫描，**不构成固定模块加载等价保证**。本轮不修改第三方源码、不新增原生执行器、不把上述反例改称现场成功。
