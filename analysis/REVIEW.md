## 冻结契约补充与当前进度口径

- 公共入口为 `src/core/core.mjs`，必需导出 `parseConfig`、`parseSingle`、`matchDirective`；浏览器与 Node 共用，无 DOM、Node 内置模块或 I/O 依赖。
- `parseSingle` 允许裸名称、单条以分号结尾的普通指令，以及一条完整的已核实 Lua block 指令。普通配置块即使为空仍为 `out_of_scope`；多条配置拒绝；词法/闭合错误优先 `parse_error`。执行计划第 7 节“空块/Lua 块 out_of_scope”与第 2.4 节及本轮明确指令冲突，审核按第 2.4 节及用户修正执行，不据此拒绝合法单条 Lua block。
- 单候选缺少 context 时，匹配保持 `context_required / missing_context`，`selected_id=null`；查询层允许读取详情作知识预览，不能改为 `matched`。页面主动选择候选也仅为预览。
- 顶层 context 为 null；孤立 server/location 不推断子系统；块头按父 context 匹配，未知块下不继承确定 context。显式与已解析 context 冲突独立返回；未核实 context 映射保留候选并返回 `context_required / unverified_context_mapping`。
- 逐项核对固定返回形状、全部 status/reason、候选稳定排序和 selected_id 不变量；失败的 SingleResult.directive 必须为 null。位置按原文 UTF-16、CRLF 一行计算；未闭父块的后代 complete=false。Lua 名单与外部 Lua 文件指令名单须来自锁定注册及实现证据，不能仅按后缀猜测。
- 静态契约为 schema_version=1；当前完整 index 与不可变 release/index 一致；详情路径为 `releases/<release_id>/directives/<id>.json`，一次查询固定索引快照。核对路径安全、重复 id、相同 release_id 不得覆盖不同内容，以及 index/detail 身份字段一致。
- 源码片段与固定完整 SHA 的指定行逐字核对（仅允许统一换行），引用和事实 source_ids 可解析；basic_verified 需要注册和回调定义证据、功能/语法/context 与补丁影响核实，registration_only 不计基础完成。
- MCP 工具名为 `query_directive`；统一结果含 status、schema_version、release_id、match、detail、markdown、detail_url、errors。知识读取失败不能变 unknown；单候选 context_required 可带有效 detail。Markdown 保留状态、版本、证据及知识缺口；源码/输入以文本展示，不执行 HTML。

### R01 / P1：页面固定发布与单项查询发布混用（未关闭）

位置：`site/app.mjs:49`、`:89`、`:111`；`src/query/knowledge.mjs:109-121`。关联 C02/C05/C06。

页面启动使用 URL 中的 release 加载 index；但 submit 调用 querySingle 时没有传递页面快照，querySingle 每次无参数 loadIndex() 读取当前发布。renderDetail 随后用页面旧 index 为新详情生成永久链接。候选按钮也用新 entry 配旧 index 预览，可能因条目不属于旧索引而失败。即使没有并发发布，直接打开历史 release 的详情页后查询也能触发。
